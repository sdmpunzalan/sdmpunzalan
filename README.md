### From source data to a clearer decision

I work on dashboards and data preparation for business and economic analysis. My public work spans product portfolio reporting in Tableau and contributions to a Python pipeline for Philippine foreign-exchange analysis.

I'm interested in the whole path from a business question to a useful result: how data is prepared, which measures matter, and how a visualization helps someone interpret them.

## Selected work

Both projects below are collaborative. Each description identifies my contribution.

### 01 · Pedalmaxxing — Product Portfolio Decision Support

**The question:** Which product subcategories should a business invest in, review, or discontinue?

An academic business intelligence project using Microsoft's AdventureWorks sample data and US CPI-U data to explore revenue, profitability, inventory, and regional patterns.

**My role: Visualization & Reporting Owner**

- Owned the dashboard design rationale, Tableau Public build, and publishing.
- Defined the dashboard page structure and visual palette for executive, profitability, and regional analysis.
- Built a visualization layer featuring KPI summaries and a Discontinue vs. Invest decision matrix.

**My tools:** Tableau Public

### 02 · Philippine Forex Dashboard — Data Pipeline Contributions

**The question:** How can exchange rates and economic indicators be brought together for analysis?

A team project combining USD/PHP exchange-rate data with economic indicators for a Streamlit dashboard. The repository includes a Python collection and preparation pipeline, Google Sheets output, a CSV dataset, and a scheduled GitHub Actions workflow.

**My contribution: Python pipeline & workflow updates**

- Contributed to the Python data collection and preparation script.
- Added diagnostic logging around Google Sheets updates to make data-load behavior easier to inspect.
- Updated workflow dependencies and API-key validation.

**Tools in my contribution:** Python · pandas · requests · Google Sheets API · GitHub Actions

[Team repository](https://github.com/Forex-DataViz/forex-dashboard) · [Pipeline code](https://github.com/Forex-DataViz/forex-dashboard/blob/main/Forex_API_V5.py) · [My commits](https://github.com/Forex-DataViz/forex-dashboard/commits/main/?author=sdmpunzalan)
